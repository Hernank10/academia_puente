# 🏛️ Academia Puente Digital - Hub Multicultural

Sistema de gestión de aprendizaje (LMS) especializado en la enseñanza del español con un enfoque multicultural y pedagógico.

## 🌟 Implementación Actual
- **Entorno Profesional**: Desplegado con éxito en PythonAnywhere.
- **Acceso Remoto**: Gestión total desde dispositivos móviles (Optimizado para Samsung Galaxy A72).
- **Arquitectura**: Django 5.x con base de datos estructurada para albergar 112 hitos pedagógicos.
- **Panel Administrativo**: Centro de mando activo para carga de contenidos en tiempo real.

## 🛠️ Estructura del Proyecto
- `Courses/`: Gestión jerárquica de Materias, Cursos y Lecciones.
- `Contents/`: Módulos de Áreas Lingüísticas y Ejercicios interactivos.
- `Static/`: Procesamiento de estilos y diseño visual profesional (UI/UX).

## 📊 Metodología de los 112 Hitos
El proyecto se basa en una ruta de aprendizaje dividida en 112 puntos clave que conectan la gramática, la fonética y la cultura hispanohablante, permitiendo al estudiante navegar por las variantes de América y España.

## 📝 Instrucciones para el Desarrollador
Para realizar mantenimiento o actualizaciones:
1. Activar entorno virtual: `source venv/bin/activate`
2. Aplicar cambios en modelos: `python manage.py migrate`
3. Recolectar archivos estáticos: `python manage.py collectstatic`
